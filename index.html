SusCheck

“The bouncer for your pip install.”

Pre-execution security orchestration. Audits package installs and repo clones before anything runs: AST checks, obfuscated-dropper detection, multi-engine SAST (Semgrep, Bandit, Checkov, Gitleaks), and MCP server scanning into a live Platform Risk Index.

HonestBackup

“Backups that ransomware can’t delete.”

3-2-1-1-0 SaaS backup platform on Azure. Pulls Microsoft 365, Notion and Cloudflare into age-encrypted, SHA-256-ledger-verified archives with WORM immutability. Microsoft Graph delta tokens cut routine transfers from ~80 MB to ~5 MB.

“An AI agent you actually own.”

Chrome MV3 browser agent: multi-tab DOM automation via the Debugger APIs. Your models, your keys, your machine: runs on local LLMs (Ollama, vLLM), and talks to cloud APIs (NVIDIA NIM, OpenAI) only if you point it there.
